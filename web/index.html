▸ APPRENDRE — leçons + référence
syntax + share

drums: kick snare hat clap — use x and .
melody: any other name — notes like c2 eb3 g4
key: key: c minor · then melody can use degrees 1-7 (1=tonic) · octave marks ' and , · alter with suffix: 7# 3b 5b
chords: UPPERCASE root = accord (plusieurs notes) — Cm7 F G7 Am Dsus4 · minuscule = note simple
arp: | arp up (down/updown/downup) sur une voix d'accords — égrène chaque accord
roman: I ii iii IV V vi vii (+7) accords diatoniques sur la gamme (nécessite key)
song: song: intro*4 verse*8 chorus*8 · tag les voix avec | in verse chorus
long: nom@section: = pattern différent d'une voix par section (ex. bass@drop: 1 1 1 1) — morceaux longs qui évoluent
son (après |): lp N / hp N filtre (+ q R résonance) · env A D S R enveloppe ADSR
synth (après |): unison N + detune C (super-saw) · drive X (disto) · lfo cutoff/pitch/gain RATE DEPTH
automation: A..B sur un param = rampe dans le temps (ex. lp 300..6000) · over N = durée en mesures
stéréo (après |): pan P (-1 gauche … 1 droite) · bus master compressé/limité (glue studio)
espace (après |): reverb N (0-1, profondeur) · delay N (0-1, écho) — send par voix
MIDI (après |): midi CH (1-16) — envoie la voix vers ton DAW/synthé matériel (drums → canal 10)
samples (après |): sample NAME — drums (bd sd hh cp kick909 clubkick oh rim cow perc tom… tabla) · mélodiques (bass arpy gtr casio sax sitar juno pad2 hoover stab bleep sid voodoo) · breaks (amen break amencut) · voix/texture (vox yeah breath wood metal glass bottle) · root NOTE pour accorder
pump: duck: 70 (ligne) — sidechain : tout le mix duck à chaque kick (groove techno)
euclid: e(k,n) ou e(k,n,rot) — k frappes réparties sur n pas (ex. kick: e(4,16))
chance: suffixe ? = probabilité (x? ~50%, x?70 = 70%) · seed: N rend l'aléatoire reproductible
rolls: suffixe *N = ratchet/roll (N frappes dans un pas) — ex. snare: . . x*4 .
vary: <a/b/c> choisit une alternative par mesure (varie le motif) · poly: voix de longueurs différentes = polyrythmie
verbs (after |): rev · fast N · slow N · every N <verb> · palindrome · rot N · iter N
timbre (after |): saw sine tri pulse square · gain N · oct N (octave par défaut des degrés)
